# Changelog

## Version 2 – SecureChat Enhancements (March 20, 2026)

### Added
- File transfer backend with upload and download routes
- Integration of file transfer with UI
- Files sent through chat as downloadable links
- Online users check and tracking functionality
- Logging system for chat sessions and activity
- Server executable (server.exe)

### Improved
- File transfer security enhancements
- Overall system stability through multiple bug fixes
- Integration between frontend UI and backend file system
- Git branch merging for feature consolidation

### Fixed
- Bugs in file transfer system
- WebSocket and routing inconsistencies
- Minor UI and backend synchronization issues

## Version 1.5 – Security & Encryption Updates (March 15–17, 2026)

### Added
- Client-side encryption (messages sent as ciphertext)
- Error handling improvements in WebSocket (ws.js)
- File transfer routes and backend structure
- Initial file transfer backend setup

### Improved
- Security of message transmission
- Backend structure for handling encrypted data

## Version 1.2 – Authentication & Protection (March 12, 2026)

- Authentication security
- Login handling and access control
